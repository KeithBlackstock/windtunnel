Wind tunnel case builder

This page produces the inputs that openfoam_case.py in KeithBlackstock/windtunnel writes into an OpenFOAM case: the duct domain, the background cell size, the snappyHexMesh refinement levels and the model placement that comes from model_transformations.json. Change a value here, copy the emitted code into the repository, run the generator.

Repository: github.com/KeithBlackstock/windtunnel branch: main generator: openfoam_case.py
Current state of the pipeline

What the repository runs today

  • Geometry export. export_stl() places the model with the saved 4×4 transform and writes case/constant/triSurface/model.stl. It warns if the mesh leaves the duct.
  • Dictionaries. write_dicts() emits controlDict, blockMeshDict, snappyHexMeshDict and meshQualityDict into case/system/.
  • Meshing. run_meshing() runs blockMesh -case case then snappyHexMesh -case case -overwrite, producing case/constant/polyMesh.
  • Dependencies that bite. find_location_in_mesh() calls mesh.contains() and trimesh.proximity.closest_point(). Both raise ModuleNotFoundError without rtree, and closest_point() also needs scipy for its KD-tree. numpy and trimesh alone are not enough.
  • locationInMesh is picked automatically: the fluid candidate with the largest clearance to wall and model surface, ties going upstream.

Values are millimetres. The generator rounds the domain to whole background cells, so pick a cell size that divides the duct exactly. Refinement level N gives a surface cell of background / 2N.

Clone and first run

        
        
git clone https://github.com/KeithBlackstock/windtunnel.git
cd windtunnel
python -m pip install numpy trimesh rtree scipy
python openfoam_case.py --stl /path/to/model.stl
blockMesh -case case
snappyHexMesh -case case -overwrite
